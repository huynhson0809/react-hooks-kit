# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-28

### Added

- `useToggle` — boolean toggle state
- `useLocalStorage` — persistent state synced with localStorage
- `useDebounce` — debounce rapidly changing values
- `useFetch` — data fetching with loading/error states and abort support
- `useMediaQuery` — responsive CSS media query matching
- `useClickOutside` — detect clicks outside a referenced element
- `usePrevious` — access the previous value of a variable
- `useInterval` — declarative setInterval with auto-cleanup
- Full test suite with Vitest
- GitHub Actions CI pipeline
- TypeScript strict mode, tree-shakeable ESM + CJS builds
